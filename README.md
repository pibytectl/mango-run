# The Mango Run (مشوار المانجا), Mission 1

A small original 2.5D browser game: an Upper Egyptian hero carries a crate of mangoes across Imbaba, Cairo, to catch the Nile ferry before sunset. Play it on a phone held sideways, or on desktop with the arrow keys, Space and X.

Built with Three.js r170 (MIT). Cairo font (OFL). Art made with image generation, music made with ACE-Step. All characters are fictional.
